# Evolution Protocol

Evolution Protocol is a browser-based sci-fi survival shooter built with HTML, CSS, JavaScript, and the Canvas API. Play as a robot escaping an evolving security facility: fight enemies, hack terminals, and reach the exit before lockdown.

## Features

- Six campaign rounds, each with a 60-second countdown
- A standalone 60-second sprint mode
- Large, procedurally generated maps with six terrain themes
- An angled 3D-style camera with mouse aiming
- Enemies that increase in number and difficulty each round
- Persistent upgrades to movement, hacking, and weapon damage
- EMP attacks, sprinting, and three difficulty settings

## How to Play

Open `evolution-protocol.html` in a modern browser—no installation required.

- **WASD / Arrow keys:** Move
- **Mouse / Left click:** Aim and shoot
- **Shift:** Sprint
- **E:** Hold to hack terminals
- **Space:** Activate EMP
- **P:** Pause

Hack every terminal to unlock the exit, then extract before time runs out.
